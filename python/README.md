# DataStream in Python

A set of helper functions ([see datastream.py](datastream.py)),
to work with HDF5 files created using DataStream.

## Pre-requisite

`h5py` can be installed using either the package manager

```shell
sudo apt install python3-h5py
```
or using the `pip` package installer

```shell
pip3 install h5py
```

## Usage

Load the script to use the helper functions and the HDF5 file
in readonly mode

```python
import h5py
import datastream as ds

file = h5py.File(/path/to/file, 'r')
```
Every function has two positional arguments: the HDF5 file
object and a path (of interest) within the file

  | Function                          | Purpose                                             |
  | :-------------------------------: | :-------------------------------------------------: |
  | `get_data(file, path)`            | Returns the entire dataset                          |
  | `get_entry(file, path, index)`    | Returns a single entry at a given index             |
  | `get_attribute(file, path, attr)` | Returns attribute by name from given path           |
  | `get_nentry(file, path, attr)`    | Returns total number of entries                     |
  | `get_dimension(file, path)`       | Returns dimension of data (of a single entry)       |
  | `get_shape(file, path)`           | Returns shape of data (length along each dimension) |

### Example

Refer to [read.py](read.py) which uses the HDF5 file generated by
[example/write.cc](../example/write.cc) and produces an identical
output that of [example/read.cc](../example/read.cc):

```shell
python3 read.py /path/to/Data.h5
```
